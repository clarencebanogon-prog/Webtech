HTML Text Formatting

1. Bold Text - <b>

The <b> tag makes text bold.

2. Strong Text - <strong>

The <strong> tag shows important text: Important!

3. Italic Text - <i>

The <i> tag makes text italic.

4. Emphasized Text - <em>

The <em> tag emphasizes text: Very important!

5. Underlined Text - <u>

The <u> tag underlines text: Underlined text.

6. Highlighted Text - <mark>

The <mark> tag highlights text: Highlighted text.

7. Small Text - <small>

The <small> tag makes text smaller.

8. Deleted Text - <del>

The <del> tag shows deleted text: Old price: P100.

9. Inserted Text - <ins>

The <ins> tag shows inserted text: New information.

10. Subscript - <sub>

The <sub> tag displays text below the normal line, such as H2O.

11. Superscript - <sup>

The <sup> tag displays text above the normal line, such as x2.

Example

HTML stands for HyperText Markup Language.
